# 📚 Blog Topic Suggester

**Blog Topic Suggester** is a modern and interactive web application that helps users generate blog topic ideas based on keywords and categories. It fetches relevant blog topics using an external API and provides clickable suggestions that lead to full articles.

---

## 🌟 Features

✅ **Keyword-Based Suggestions** – Enter a keyword, and the app suggests relevant blog topics.  
✅ **Category Filtering** – Choose from predefined categories like Technology, Health, Finance, etc.  
✅ **Clickable Suggestions** – Each suggestion links directly to the full blog article.  
✅ **Elegant & Responsive UI** – Styled with a **custom color palette** for an appealing and modern design.  
✅ **Error Handling & Feedback** – Provides clear messages when no topics are found.

## 🛠️ Technologies Used

- **React.js** – Frontend framework for building the UI.
- **Axios** – To fetch blog topics from the external API.
- **Tailwind CSS** – For styling and responsiveness.
- **Node.js & Express** (Backend API - Optional if using custom API).

## 🚀 Installation & Setup

Follow these steps to **run the project locally**:

### 1️⃣ **Clone the Repository**
```sh
git clone https://github.com/Stephanie514/Web-Development.git
cd blog-topic-suggester

### **2️⃣ Install Dependencies**
```sh
# Install frontend dependencies
cd frontend
cd my-app
npm install

# Install backend dependencies
cd backend
npm install
```

### **3️⃣ Set Up Environment Variables**
Create a `.env` file in the `backend` directory and add:
```env
API_KEY=your_news_api_key
```

### **4️⃣ Start the Application**
```sh
# Start the backend server
cd backend
npm start

# Start the frontend
cd frontend
cd my-app
npm start
```

The app will be available at `http://localhost:3000`.
