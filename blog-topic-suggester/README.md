#  Blog Topic Suggester

The **Blog Topic Suggester** is a React-based web application that helps users generate blog topic ideas based on keywords. It fetches real-time blog topics from an API and allows users to explore different categories.

## 🚀 Features
✅ **Keyword-Based Suggestions** – Enter a keyword, and the app fetches related blog topics.  
✅ **Category Filters** – Users can explore topics by categories like Technology, Health, Finance, etc.  
✅ **Clickable Blog Titles** – Each suggested topic is linked to its original source.  
✅ **Modern & Responsive UI** – Styled with a beautiful **purple & pink color palette**.  
✅ **Interactive UX** – Hover effects, smooth transitions, and intuitive design.

## 🎨 Tech Stack
- **Frontend:** React.js
- **API Calls:** Axios
- **Styling:** Tailwind CSS & Custom CSS
- **Backend:** API (Expected at `http://localhost:5000/api/topics/news`)

## 🖥️ Installation & Setup

1. **Clone the repository**  
   ```sh

   cd blog-topic-suggester


### **2️⃣ Install Dependencies**
```sh
# Install frontend dependencies
cd Frontend
cd my-app
npm install

# Install backend dependencies
cd Backend

```

### **3️⃣ Set Up Environment Variables**
Create a `.env` file in the `backend'directory and add:
```env
API_KEY=api_key
```

### **4️⃣ Start the Application**
```sh
# Start the backend server
cd Backend
npm start

# Start the frontend
cd Frontend
cd my-app
npm start
``
